### 2. DPD
- [ ] **עדכון הספר:** להוסיף את נוסחת המימוש:
  \[
  DPD=\frac{1}{|W|}\sum_{(i,j)\in W}|a_i-b_j|.
  \]
- [ ] להגדיר את הרצפים הדומיננטיים a ו־b, את מסלול היישור W ואת נרמול המרחק באורכו.
- [ ] לציין שהמימוש משתמש ב־FastDTW מקורב, בקיפול ל־12 מחלקות גובה ובבחירת argmax אחד בכל frame.
- [ ] להבהיר שהעלות היא הפרש מספרי לא מעגלי בין מחלקות הגובה, ושאין במדד בדיקה מלאה של שתי מלודיות או של אוקטבות.

מיקום מוצע: report/sections/02_background.tex, לצד ההסבר ונוסחת Jaccard הקיימים.

### 3. Multipitch ברמת frame
- [ ] **עדכון הספר:** להגדיר TP_t, מספר גבהי האמת N_ref,t ומספר גבהי האומדן N_est,t.
- [ ] להוסיף:
  \[
  P_{\mathrm{frame}}=\frac{\sum_t TP_t}{\sum_t N_{\mathrm{est},t}},\qquad
  R_{\mathrm{frame}}=\frac{\sum_t TP_t}{\sum_t N_{\mathrm{ref},t}}.
  \]
  \[
  A_{\mathrm{frame}}=
  \frac{\sum_t TP_t}
  {\sum_t(N_{\mathrm{ref},t}+N_{\mathrm{est},t}-TP_t)}.
  \]
- [ ] לציין ש־F1 מחושב מ־P ו־R אלה, ולהבחין בין multipitch accuracy לבין accuracy של קלאסיפייר הכלים.
- [ ] להבהיר שהפרוטוקול משתמש ברשת זמנים משותפת, ושה־onset tolerance של מדד האירועים אינו חל על מדד זה.

מיקום מוצע: report/sections/02_background.tex; פרטי קצב הזמן ב־report/sections/06_experiments.tex.

### 4. הממוצע וה־covariance ב־FAD
- [ ] **עדכון הספר:** להגדיר וקטור embedding לכל הקלטה e_i ואת גודלו d.
- [ ] להוסיף לפני נוסחת FAD הקיימת:
  \[
  \mu=\frac1n\sum_{i=1}^{n}e_i,\qquad
  \Sigma=\frac1{n-1}\sum_{i=1}^{n}(e_i-\mu)(e_i-\mu)^\top.
  \]
- [ ] להבהיר: CLAP מפיק וקטור של 512 מאפיינים ו־covariance בגודל 512×512; ב־EnCodec נעשה mean pooling בזמן לקבלת 128 מאפיינים ו־covariance בגודל 128×128.
- [ ] להבחין בין ממדים אלה לבין 128 שורות pitch בכל מפת MIDI.

מיקום מוצע: report/sections/02_background.tex; פרטי ה־pooling ב־report/sections/06_experiments.tex.

### 5. Target Present ו־Exact Target Set
- [ ] **עדכון הספר:** להגדיר קבוצת כלי יעד S_target וקבוצת תוויות חזויות S_hat,i.
- [ ] להוסיף את הגרסאות המתמטיות של ההגדרות המילוליות שכבר קיימות:
  \[
  A_{\mathrm{present}}=\frac1N\sum_{i=1}^{N}
  \mathbf1[S_{\mathrm{target}}\subseteq\widehat S_i],
  \]
  \[
  A_{\mathrm{exact}}=\frac1N\sum_{i=1}^{N}
  \mathbf1[S_{\mathrm{target}}=\widehat S_i].
  \]
- [ ] להסביר את פונקציית האינדיקטור ואת סף ההחלטה 0.5.
- [ ] לשמור על ההבחנה: זיהוי כלי אינו בדיקה של שיוך מלודיה לכלי.

מיקום מוצע: report/sections/06_experiments.tex.

### 6. השלמת פונקציות המשקל וה־preconditioning
- [ ] **עדכון הספר:** לצד פונקציית ההפסד הקיימת, לפרט את המשקל:
  \[
  \lambda(\sigma)=
  \frac{\sigma^2+\sigma_{\mathrm{data}}^2}
  {(\sigma\sigma_{\mathrm{data}})^2}.
  \]
- [ ] לצד נוסחת ה־denoiser הקיימת, להגדיר:
  \[
  c_{\mathrm{skip}}=\frac{\sigma_{\mathrm{data}}^2}
  {\sigma^2+\sigma_{\mathrm{data}}^2},\quad
  c_{\mathrm{out}}=\frac{\sigma\sigma_{\mathrm{data}}}
  {\sqrt{\sigma^2+\sigma_{\mathrm{data}}^2}},
  \]
  \[
  c_{\mathrm{in}}=\frac1{\sqrt{\sigma^2+\sigma_{\mathrm{data}}^2}},\qquad
  c_{\mathrm{noise}}=\frac14\log\sigma.
  \]
- [ ] לציין שבמימוש הנוכחי sigma_data=1 ולוודא עקביות סימונים עם סטיית התקן של נרמול הדומיין.

מיקום מוצע: report/sections/04_baseline.tex.
